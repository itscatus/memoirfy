# Memoirfy
Memoirfy is a simple diary web-app that can be accessed through pc and mobile phone using browser. Write and record every moment in your day using this app!

|Deployment link: https://memoirfy.vercel.app/

The framework used for front-end design is Vite+Vue with Tailwind.css
This website was deployed using vercel
The backend was hosted using Pockethost with the framework Pocketbase
